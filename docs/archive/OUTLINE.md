# 《满天星》大纲 v0.1

## 一页纸

**一句话**
一个准备离开的咖啡店老板、一个被裁员的程序员、一个想埋葬旧自己的店员；一杯咖啡送一个小手工，一座模型葬礼，和一场谁先开口的争吵。

**主题**
爱不是拯救，是陪伴；不是替对方决定，是一起把日子过小一点、真一点。

**基调**
干净、单纯、温柔。没有性内容、没有安全词、没有性羞耻词。悲伤但不残忍。

**地点**
一家咖啡店：主营咖啡，次要手工；买一杯咖啡，送一个小手工。店里有旧钢琴、门口的铃、墙上的小手工、后间的模型葬礼。

**人物**
- 沈岚，24，老板；玩家视角；准备离开，也准备把店留给小满。
- 陆遥，25，大厂程序员；被裁员；隐瞒牺牲，想用「修」留住她。
- 林小满，22，美院/手作专业，兼职店员；沈岚最好的朋友；给自己办葬礼，埋葬「太乖的旧自己」。
- 老周，60 多，退休调琴师；钢琴的来历；长辈/见证者。
- 房东，40 多；关店倒计时；不是坏人。
- 阿哲，28，陆遥的前同事/猎头；那个外地 offer。
- 小满妈妈，40 多（电话）；小满的退路/压力。
- 考研女孩、老李：常客小片段。

**结构**
不是顺叙，也不是纯倒叙：**四个乐章 + 16 个「记录」+ 葬礼锚点**。同一乐章内可自由选择记录顺序；玩家自己拼出时间线。
**一周目：沈岚视角。二周目：陆遥视角。** 同样的故事，不同的内心。

**结局**
7 个：一起开（真）、接受牺牲（白夜）、朋友一个人开、没有回头、她和他走、收进盒子、完成葬礼（一周目可达成）。

## 四个乐章

### 第一乐章 · 坠落（记录 1–4）
店要关了；沈岚在准备离开；小满在给自己办葬礼；陆遥被裁员，走进店里。
**情绪**：安静、下坠、一点好笑。

### 第二乐章 · 点星（记录 5–9）
咖啡 + 小手工的日常；教琴；书页边的对话；门口的灯；雨里的伞；小满的本子。
**情绪**：甜、暖、具体；越甜后面越疼。

### 第三乐章 · 抬头（记录 10–13）
租约、offer、凌晨 3:47；模型底座的解谜；争吵；双重真相。
**情绪**：紧、疼、互相看见。

### 第四乐章 · 告别（记录 14–16）
琴盖合上；展览/关门；二周目。
**情绪**：释然、温暖、或者苦涩。

## 分支图

```
谁打开模型底座？
├─ 小满 → 朋友线：她先看到信
├─ 陆遥 → 爱情线：他先看到信
└─ 自己 → 收进盒子

争吵
├─ 冷静 → 理解 → 拥抱
└─ 越吵越凶 → 不欢而散

牺牲
├─ 拒绝 → 他保留未来
└─ 接受 → 白夜结局

走/留
├─ 留下 → 一起开
├─ 走 + 告知小满 → 朋友一个人开（原谅）
├─ 走 + 不告而别 → 没有回头（不原谅）
└─ 跟他走 → 她和他走
```

### 7 个结局

1. **一起开（真）**：拒绝牺牲 + 留下 + 冷静 + 告知小满。店变小，做成展览/工作坊；他保留未来；小满一起。
2. **接受牺牲（白夜）**：接受 + 留下。店保住，债在他身上；爱是真的，但不再平等。
3. **朋友一个人开**：她走，告知小满。小满接手；原谅。
4. **没有回头**：她走，不告而别。小满接手；不原谅。
5. **她和他走**：拒绝牺牲 + 跟他走。小满接手；她第一次为自己选。
6. **收进盒子**：自己打开/谁也没告诉。店关了，模型还在。
7. **完成葬礼（一周目可达成）**：她谁也没告诉，把模型做完。小满和陆遥一起参加她的葬礼；店没有开门。

### 完成葬礼 · 最终场景

- **触发**：她谁也没告诉，把模型做完；不求助、不打开底座、不赴约。
- **视角**：第一次离开沈岚的视角；镜头在她之外。
- **画面**：小雨，墓地；墓碑前摆着店里的手工；模型葬礼放在碑前；小满和陆遥并排站着，一个拿纸星，一个拿店钥匙。
- **声音**：没有对白；钢琴版《Touch the starlight》放到一半停掉。
- **最后一行**：那天，店没有开门。
- **之后**：可以放一页安静的心理援助信息，不做说教。

## 二周目：陆遥视角

**解锁**：任意一周目结局后，主菜单出现「以陆遥的视角重看」。

**同样的场景，不同的内心：**
- 第一次进店：他刚被裁员，面试取消；他看见小满在办葬礼，看见沈岚在柜台后面；他接过那颗写着「撑住」的星。
- 每天来店里：不是「常客」，是「没有地方可去」。
- 刷卡机/钢琴/门口的灯：他每一次「修」，都是想说「我有用，别赶我走」。
- 租约/offer/凌晨 3:47：他终于看见自己是怎样把「爱」做成一笔债。
- 争吵：第一遍你听见她问「你为什么不告诉我」；第二遍你听见自己心里说「因为告诉你，你就走了」。

**新增的选择（只在他的视角里）：**
- 发现租约/offer 时：告诉她 / 继续瞒。
- 收到 offer 时：走 / 留。
- 争吵时：说出真相 / 继续用「我只是想帮你」挡。
- 结尾：接受她的拒绝 / 把 offer 拿回来。

**完成葬礼（他的视角）**：
- 他和小满并排站在墓前。
- 他手里是那颗「撑住」的星；小满手里是店钥匙。
- 这一次，玩家不是她，是留下来的人。

## 二周目新结局：如果那天我说了

- **触发**：陆遥视角，在发现租约/offer 或争吵时，选择「告诉她」而不是继续瞒。
- 他第一次把两件事摊开：赔偿金付了租约、offer 拒了、夜里在跑活。
- 她也第一次摊开：店要关、她在准备离开、钥匙和信在模型底座里。
- 两个人还是吵，但吵的是「以后怎么办」，不是「你为什么骗我」。
- **结果**：店变小/做展览；他拿远程或保留 offer；小满一起；不是完美，但没人再瞒。
- **最后一行**：「那天我说了。店还是小了，但我们都在。」

**呈现方式**：
- 第一遍：这些只是生活细节，玩家可以忽略；不推进剧情。
- 第二遍：同样的场景，他的内心旁白浮出来；第一遍的句子变成灰色，他的真话叠在上面。
- 记录里出现两栏：「她看到的」/「他没说的」。
- 第二遍的星图是「他的星」，不是她的。

**钩子与结局**：
- 二周目的「告诉她」选择不要求集齐钩子；但集齐越多，「都说开了」的结尾越完整。
- 第一遍错过钩子没关系；第二遍会在记录里标出「你当时没看见的」。

## 待定

1. **打击**：暂定「楼要卖/租金翻倍/店有欠租」。她一直在用自己的钱补贴「买咖啡送手工」。
2. **模型底座**：暂定沈岚把底座粘死，自己不敢开；叫小满/陆遥/自己掰。
3. **信**：写给小满，还是写给「未来的店长」？暂定写给小满。
4. **结局数量**：7 个会不会太多？可以合并「朋友一个人开」和「没有回头」。
5. **二周目**：陆遥视角重述；同样的场景，他的内心、裁员、offer、租约、夜班；新增几个「说不说」的选择。是否加一个新结局，待定。
