# 《满天星》立绘矩阵 v0.1

## 规则

- **对话用半身**：头到腰/手，表情清楚，不挡背景。
- **关键场景用全身/动作**：钢琴坐姿、跪着摆模型、雨里、展览。
- **全部透明 PNG**；生成后去边缘（defringe），保持同一张脸。
- **命名**：`角色_姿态_表情.png`。
- **一致性**：用中立立绘或角色设定图做 reference，同一角色同一套衣服。
